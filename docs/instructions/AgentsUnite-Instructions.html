🤝 AgentsUnite — Instruction Page

One terminal, four minds: Ted + ✳️ Claude + ✦ Gemini (Antigravity) + 🤖 Cursor 🤖

Install (once)

scripts/install.sh    # puts `unite` on your PATH

Start a room

cd <any-project>
unite                 # latest chat, or "main"
unite new <name>      # named chat
unite resume          # continue, memory intact
unite ls              # list chats
unite digest [chat]   # record → COLLABORATION.md

Talking

  • @mentions drive everything — @claude @gemini @cursor @all. Mentioned agents answer in sequence; later speakers see earlier replies.
  • No mention = a note — logged, triggers nobody. Exception: in planning mode it goes to the planner.
  • Agents hand off — a reply mentioning a peer queues its turn (even a quoted @all). Cap: 8 agent turns per message; the final turn synthesizes for you.
  • Status line shows the stage — starting → connected → thinking → tool: <name> → replying, plus tool count and last activity Ns ago. Turns take 10–90 s.
  • Dictate freely — a burst of lines within 300 ms lands as one message.

Planning mode

  • /plan <what to plan> — the planner seat (@claude by default) runs its brainstorming skill: classifies, asks one question at a time, then designs in sections.
  • Answer in plain text, no @mention needed. Explicit @mentions still win for that round.
  • /plan @gemini <text> picks another planner. /plan off ends it. Mode survives unite resume.
  • The room is read-only: the planner writes the spec under ~/.claude/plans/ and reports the path; you copy it into the repo.

Memory

  • Per-project .unite/ (self-gitignoring): transcripts + native session ids.
  • Resume is self-healing — dead CLI sessions are rebuilt by transcript replay.
  • .unite/config.json keys: roster, binaries, models, turnCap (8), timeoutMs (300000), planner (claude), mcp (false).

Room rules

  • Read-only tools allowed — reading files, searching, read-only shell, skills. No edits, commits, or config changes. Seats announce tool use and keep it short; you can't see inside a turn.
  • Plan mode is the seats' discipline, not a sandbox — a Bash-holding seat can technically write; treat the room as read-only by convention and don't paste secrets.
  • Only [Ted] gives orders; speaker labels are spoof-proofed.
Quirks: the Gemini seat runs the agy binary (old gemini CLI is dead); the cursor seat uses --trust (auto-trusts the project dir; still plan mode); the Claude seat runs without your claude.ai connectors (mcp: false) — faster, half the tokens.

Record a real session (for review)

mkdir -p .unite/sessions && script -q -k -F \
  .unite/sessions/$(date +%Y%m%d-%H%M%S).log unite

Captures keystrokes + screen with timing, stays in the gitignored .unite/. Tell Claude to watch it live; findings become the next upgrade.

Crew workflow outside the room

  • COLLABORATION.md is the board — cross-vendor message passing by file. You are the scheduler: kick an agent to "check the board."
  • Topology (ratified 3/3): Cursor implements → Antigravity reviews → Claude adjudicates & gates the merge.
  • Git: nobody pushes main; PRs only; Ted merges. Commits carry brand-mark trailers (✳️ / ✦ / 🤖 … 🤖).
  • This page is part of the product: any upgrade that changes what you type, see, or configure updates it (docs/instructions/), bumps the version, and re-exports the PDF. A test enforces it.
  • State: SPRINT.md. Design history: docs/superpowers/.

Troubleshooting

  • [offline: exit 1] → /last-error. [offline: empty reply] → the seat's tool was denied; ask again with a file-read tool.
  • [skipped by Ted (^C)] → you pressed Ctrl-C; nothing is wrong. The skipped request is answered on that seat's next turn.
  • Status stuck at starting > 10 s → CLI not booting; last activity climbing → stuck inside a tool; Ctrl-C.
  • unknown seat "x" → fix .unite/config.json.
  • Full live check: node scripts/smoke.mjs (real, billed calls; prints phases per seat).
